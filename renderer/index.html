Comment fonctionne la connexion

Tu te connectes sur la vraie page roblox.com, dans une fenêtre séparée. Stellar ne voit jamais ton mot de passe : il garde seulement la session Roblox, isolée par compte et stockée uniquement sur ce PC. Retirer un compte le déconnecte aussi côté Roblox.

Détection…

Toujours utiliser la carte NVIDIA pour Roblox
Réglage Windows « Hautes performances » pour Roblox, réappliqué à chaque mise à jour. Évite que Roblox tourne sur la puce Intel, beaucoup plus lente. Réversible.

Le réglage « un petit peu » (marche dans Roblox)

Les filtres Alt + F3 de NVIDIA ne marchent que dans les jeux que NVIDIA prend en charge. Si le panneau affiche « Démarrer un jeu pris en charge » avec Roblox ouvert, Roblox n'en fait pas partie. Ces deux réglages du pilote marchent dans tous les jeux, Roblox compris :

🎨 Couleurs plus vives0 % de FPS

Appli NVIDIA → Système → Affichage → Vibrance numérique : passe de 50 % à environ 65 %.

S'applique à tout l'écran, pas seulement à Roblox. Remets 50 % pour revenir comme avant.

🔍 Image plus nette~1 % de FPS

Appli NVIDIA → Graphismes → Paramètres de programme → ajoute Roblox → Mise à l'échelle de l'image : active-la et règle la netteté vers 30-40 %.

C'est ce qui ressemble le plus à l'effet « DLSS ». Les noms peuvent légèrement changer selon la version de l'appli.

Les gros « shaders » qui font ramer ajoutent des effets lourds (éclairage simulé, occlusion ambiante, profondeur de champ) par-dessus le jeu. Ces deux réglages-là n'en font pas partie. Astuce PC portable : branche le chargeur, sinon la carte graphique est bridée.

Pas de carte NVIDIA détectée

Sur AMD : logiciel Adrenalin → Jeux → Graphismes → active Radeon Image Sharpening (netteté ~50 %), puis Affichage → Saturation +10 à 20. Sur une puce Intel seule, garde le profil Performance dans Paramètres.

Sons de l'interface

Tes réglages Roblox

Lus directement dans Roblox. Ils se changent en jeu : Échap → Paramètres (Fréquence d'images maximale, Qualité graphique). Roblox n'accepte plus qu'un launcher change la limite de FPS.

Profil graphique

Un clic pour régler la qualité de tous tes jeux. Ça passe par les réglages officiels de Roblox : rien n'est injecté dans le jeu, donc aucun risque de ban. Plus le profil est élevé, plus il demande à ta carte graphique.

Graphismes avancés

Ces réglages remplacent ceux du profil.

Désactiver les ombres
Gros gain de FPS sur les cartes chargées.
Désactiver le post-traitement
Retire le flou, le bloom et les effets de couleur.
Désactiver l'herbe
Plus de FPS sur les terrains avec de l'herbe.
Moteur de rendu
Anticrénelage (MSAA)
Qualité des textures

Éditeur de FastFlags

Pour les experts : ajoute tes propres flags en JSON. Ils passent en dernier et remplacent tout le reste.

Roblox n'applique que les flags de sa liste autorisée ; les autres sont ignorés sans danger.
